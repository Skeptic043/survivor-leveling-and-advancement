# Survivor Leveling & Advancement [B42]

スキルを育ててポイントを獲得し、好きなスキルに使えます。SLAは通常のスキル画面に生存者レベルと先行強化ポイントを追加し、通常のスキル成長も維持します。次の失敗で死んでも、成長の一部を残したいなら、任意のレベル継承を利用できます。次のキャラクターに生存者レベルの一定割合と、新たに使えるポイントを引き継ぎます。

シングルプレイ、マルチプレイ、画面分割、コントローラーに対応。必須の前提MODはありません。

## 先行強化の仕組み

対応スキルで得たXPは生存者レベルも上げます。生存者レベルが1上がるたび、先行強化ポイント（AP）を1獲得。スキル横の **+** ボタンで使えます。初期設定では先行強化枠を同時に3枠使用できます。強化したスキルを練習し、省略したXPを稼ぐと枠が空きます。そのXPは次のスキルレベルにも加算されます。

スキルの実際の上限に達する最後の強化（通常はレベル9から10）は、スキルの習得完了として扱います。2 APと空き枠2つが必要で、その後、そのスキルが使用中の枠をすべて解放します。「全スキル共通」または「スキルごと」の上限が1なら、必要な空き枠は1つですが、費用は2 APです。「無制限」では枠は不要で、費用は同じく2 APです。実際の上限に達したスキルからは、追加の生存者XPを得られません。

## 死後も成長の一部を継承

生存者レベルの継承を有効にすると、同じワールドの次のキャラクターに残す割合を設定できます。例えば生存者レベル20で死亡し、継承率が50%なら、次のキャラクターは生存者レベル10と10 APを獲得します。以前のスキルレベルはコピーされず、継承したポイントの使い道を選べます。継承は任意で、初期設定では無効です。

## 設定

- **全スキル共通:** 全スキルで先行強化枠を共有。枠数は変更でき、初期設定は同時に合計3枠です。
- **スキルごと:** スキル別に枠の上限を設定。対応カスタムスキルには既定値を使い、標準スキルには個別の上限も設定できます。
- **無制限:** 先行強化枠の上限と、通常の成長が追いつくまでの制限をなくします。
- スキルXPを変えずに生存者XPの獲得速度を調整できます。フィットネス、筋力、標準スキルそれぞれと対応カスタムスキルを加算対象にするか選べます。
- MODオプションで強化マーカーのコントラストを上げたり、プレイヤー1の生存者XPの割合をデジタル時計に表示したりできます。
- Project Zomboidの言語設定にある標準言語すべてに対応。翻訳はすべてAIのみで作成しました。誤訳や分かりにくい表現があればご報告ください。

**注意:** モードを変えても記録済みの進捗はリセットされません。「無制限」で得た通常のスキルXPも、保存されている青色の追いつき待ち分を減らします。「全スキル共通」や「スキルごと」に戻すと、残りの分だけが復元されます。

## SLAの追加と削除

既存のセーブに追加・削除できます。スキルは維持され、過去の成長に対して生存者レベルが後から付与されることはありません。無効化すると画面表示は消えますが、APで得たスキルレベルは残ります。再有効化するとSLAの状態が復元され、不在中の対応する成長も反映されます。MOD構成を変更する際は、大切なプレイ中のワールドを必ずバックアップすることを強くお勧めします。

## 専用サーバーとホストプレイ

管理者は既存のオンライン・オフライン両方のプロフィールに、生存者XPや整数単位のレベルを付与できます。オフラインへの付与も即時反映されます。「先行強化を解除」はAPを返還せず、スキルXPも変えずに枠を空けます。オフラインのキャラクターへの解除は再接続まで保留され、それまでは取り消せます。プレイヤー統計からスキルレベルを編集すると、そのスキルの管理記録が消去されます。

SLAはProject Zomboidの通常のセーブを使います。ホスト・専用サーバーではSaveWorldEveryMinutesを有効にし、通常の手順でサーバーを終了してください。

## 互換性

- **非互換: [RPG Skills Systems B42 / RPGMenu](https://steamcommunity.com/sharedfiles/filedetails/?id=3666281346)**
- **現在未対応: [Beyond Ten - Level 15 Skills](https://steamcommunity.com/sharedfiles/filedetails/?id=3765241705) と [Seesaw Game](https://steamcommunity.com/sharedfiles/filedetails/?id=3515515643)**。SLAが必要とする成長ルールを直接置き換えます。
- **読み込み順に依存: [Detailed Skill Tooltips](https://steamcommunity.com/sharedfiles/filedetails/?id=3572846242)**。SLAをDetailed Skill Tooltipsの後に読み込むと、DSTの拡張スキルツールチップにSLAの青い追いつき待ちテキストを追加できます。SLAが先なら、このテキストだけが上書きされます。生存者レベルの成長と+ボタンのツールチップは引き続き機能します。
- **併用テスト済み: [Detailed Skill Tooltips](https://steamcommunity.com/sharedfiles/filedetails/?id=3572846242)、[Toughness Skill](https://steamcommunity.com/sharedfiles/filedetails/?id=3545533939)、[Show Skill XP Gain B42.20](https://steamcommunity.com/sharedfiles/filedetails/?id=3776490883)**。この組み合わせはテストで問題なく動作しました。ただし、すべてのUIやカスタムスキルMODとの互換性は保証できません。
- スキルXP処理、上限や成長曲線、スキル画面、プレイヤーメニュー、デジタル時計表示を置き換えるMODは競合する可能性があります。必要なフックが置き換えられると、SLAは該当連携を無効にします。対応カスタムスキルには、利用可能なXP曲線と対応XPイベントが必要です。スキルの直接設定や、対応XPイベントを伴わない成長では生存者XPは発生しません。
