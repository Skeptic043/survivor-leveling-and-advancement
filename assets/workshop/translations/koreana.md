# Survivor Leveling & Advancement [B42]

기술을 올려 포인트를 얻고 원하는 기술에 사용하세요. SLA는 자연스러운 성장을 유지하며 기술 창에 생존자 레벨과 성장 포인트를 추가합니다. 선택 기능인 계승을 켜면 다음 캐릭터가 생존자 레벨의 일부와 새 포인트를 받습니다.

싱글플레이, 멀티플레이, 화면 분할, 컨트롤러를 지원합니다. 필수 선행 모드는 없습니다.

## 성장 방식

지원되는 기술에서 얻는 XP는 생존자 레벨도 올려 줍니다. 생존자 레벨마다 성장 포인트인 AP를 1씩 얻습니다. 기술 옆의 **+** 버튼으로 AP를 사용하세요. 기본적으로 성장 슬롯 3개를 동시에 사용할 수 있습니다. 포인트로 올린 기술을 연습해 건너뛴 XP를 채우면 해당 슬롯이 비워집니다. 이 XP는 기술의 다음 레벨에도 반영됩니다.

기술의 실제 최고 레벨에 도달하는 마지막 성장, 보통 9레벨에서 10레벨로의 성장을 숙달로 취급합니다. 숙달에는 AP 2와 빈 성장 슬롯 2개가 필요하며, 이후 해당 기술의 사용 중인 슬롯을 모두 비웁니다. 전체 또는 기술별 슬롯 한도가 1이면 빈 슬롯 1개만 필요하지만 AP 비용은 2로 유지됩니다. 자유 모드는 슬롯이 필요 없으며 AP 비용은 여전히 2입니다. 실제 최고 레벨에 도달한 기술은 추가 생존자 XP를 생성하지 않습니다.

## 사망 후에도 일부 진행도 유지

생존자 레벨 계승을 켜고 같은 세계의 다음 캐릭터에게 얼마나 넘길지 정하세요. 예를 들어 생존자 레벨 20에서 사망하고 계승률이 50%라면, 다음 캐릭터는 생존자 레벨 10과 사용할 AP 10을 받습니다. 이전 캐릭터의 기술 레벨은 복사되지 않으므로 계승한 포인트를 어디에 쓸지 새로 선택할 수 있습니다. 계승은 선택 기능이며 기본적으로 꺼져 있습니다.

## 설정

- **전체:** 모든 기술이 하나의 조절 가능한 성장 슬롯 한도를 공유합니다. 기본 한도는 총 3개입니다.
- **기술별:** 각 기술에 별도 슬롯 한도를 설정합니다. 호환되는 추가 기술에 적용할 기본값과 기본 게임 기술별 개별 설정을 제공합니다.
- **자유:** 성장 슬롯 한도와 건너뛴 XP를 채우는 데 따른 제한을 없앱니다.
- 기술 XP를 바꾸지 않고 생존자 XP 획득 속도를 조절하세요. 체력, 근력, 개별 기본 기술, 호환되는 추가 기술의 기여 여부를 선택할 수 있습니다.
- 모드 옵션에서 대비가 높은 성장 표시를 켜거나 디지털 시계에 플레이어 1의 생존자 XP 백분율을 표시할 수 있습니다.
- Project Zomboid 언어 설정에 있는 모든 일반 언어를 지원합니다. 모든 번역은 전적으로 AI로 작성했습니다. 잘못되거나 이해하기 어려운 문구가 보이면 알려 주세요.

**참고:** 모드를 바꿔도 기록된 진행도는 초기화되지 않습니다. 자유 모드에서 자연스럽게 얻은 기술 XP도 남아 있는 파란색 보충 진행도에 반영됩니다. 전체 또는 기술별 모드로 돌아가면 아직 남은 부분만 복원됩니다.

## SLA 추가와 제거

기존 저장 파일에 SLA를 추가하거나 제거할 수 있습니다. 기존 기술은 유지되며 과거의 성장은 생존자 레벨로 소급 지급되지 않습니다. SLA를 끄면 인터페이스가 숨겨지지만 AP로 얻은 기술 레벨은 남습니다. 다시 켜면 SLA 상태를 복원하고, 꺼져 있던 동안 얻은 지원 가능한 진행도를 반영합니다. 모드 목록을 변경할 때는 언제나 소중한 세계의 저장 파일을 백업할 것을 강력히 권장합니다.

## 전용 서버와 호스팅

관리자는 기존 온라인 및 오프라인 프로필에 생존자 XP나 정수 단위 레벨을 지급할 수 있습니다. 오프라인 지급도 즉시 적용됩니다. 승급 초기화는 AP를 환불하거나 스킬 XP를 바꾸지 않고 슬롯을 해제합니다. 오프라인 캐릭터의 초기화는 재접속까지 대기하며 취소할 수 있습니다. 플레이어 통계에서 스킬 레벨을 변경하면 해당 스킬의 승급 기록이 지워집니다.

SLA는 Project Zomboid의 일반 저장을 사용합니다. 전용 서버와 호스팅 서버에서는 SaveWorldEveryMinutes를 켜고 서버를 정상적으로 종료하세요.

## 호환성

- **호환되지 않음: [RPG Skills Systems B42 / RPGMenu](https://steamcommunity.com/sharedfiles/filedetails/?id=3666281346)**
- **현재 지원하지 않음: [Beyond Ten - Level 15 Skills](https://steamcommunity.com/sharedfiles/filedetails/?id=3765241705), [Seesaw Game](https://steamcommunity.com/sharedfiles/filedetails/?id=3515515643)**. SLA가 의존하는 성장 규칙을 직접 교체하는 모드입니다.
- **불러오기 순서에 영향받음: [Detailed Skill Tooltips](https://steamcommunity.com/sharedfiles/filedetails/?id=3572846242)**. SLA를 Detailed Skill Tooltips 다음에 불러오면 DST의 확장된 기술 설명에 SLA의 파란색 XP 보충 문구가 추가됩니다. SLA를 먼저 불러오면 이 문구만 대체되며, 생존자 레벨 성장과 + 버튼 설명은 계속 작동합니다.
- **함께 테스트함: [Detailed Skill Tooltips](https://steamcommunity.com/sharedfiles/filedetails/?id=3572846242), [Toughness Skill](https://steamcommunity.com/sharedfiles/filedetails/?id=3545533939), [Show Skill XP Gain B42.20](https://steamcommunity.com/sharedfiles/filedetails/?id=3776490883)**. 이 조합은 테스트에서 문제없이 작동했지만 모든 인터페이스 모드나 추가 기술 모드와의 호환성을 보장할 수는 없습니다.
- 스킬 XP 처리, 최대 레벨이나 XP 곡선, 스킬 패널, 플레이어 메뉴, 디지털시계 표시를 교체하는 모드는 충돌할 수 있습니다. 필요한 후크가 교체되면 SLA는 해당 연동을 비활성화합니다. 사용자 지정 스킬에는 사용 가능한 XP 곡선과 지원되는 XP 이벤트가 필요합니다. 스킬을 직접 변경하거나 지원되는 이벤트 없이 진행하는 방식은 생존자 XP를 생성하지 않습니다.

## AI 사용

모든 코드는 AI로 작성했습니다. 아이디어, 설계, 테스트, 디버깅, 출시 결정은 제 몫입니다. 직접 많은 시간을 들여 SLA를 테스트하고 문제를 해결했습니다. AI로 개발된 모드를 원하지 않는 선택도 이해하고 존중합니다.
